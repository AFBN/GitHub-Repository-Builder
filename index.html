GitHub Repository Publisher

Authenticate with a GitHub Personal Access Token. The token stays in browser memory only (sandbox-safe for WordPress custom HTML blocks). No client secret, no redirect, no external proxy required.

How to use

  • Create a classic PAT at github.com/settings/tokens with the repo scope.
  • Paste the token and click Connect.
  • Enter repository name, description and choose visibility.
  • Edit the branding files (README, index.html, style.css, script.js) directly in the text areas, or use the Load from File buttons. You can remove any branding file you don't want published by clicking the red ✕ button.
  • Restore removed branding files via the "Restore" list that appears below.
  • Optionally upload additional .txt, .docx or .pdf files that will be committed alongside the branding files.
  • Add custom text files using the Add File modal – pick a language type and provide content. You can later edit any custom file by clicking the Edit button next to it.
  • Click Publish to create the repository and push all files in one step. Repository name, description, current year and your connected GitHub username are applied automatically from the connected account and the form fields.
